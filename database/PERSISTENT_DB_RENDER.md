# تثبيت قاعدة البيانات على Render (Persistent DB)

## المشكلة
عند كل **بناء جديد** (git push → rebuild) على Render يُنشأ container جديد بنظام ملفات نظيف، فتُفقد قاعدة بيانات SQLite (`nova.sqlite`) ويُعاد بناؤها من الصفر مع كل بناء. (إعادة التشغيل/wake لا تفقد البيانات — فقط إعادة البناء).

## الحل المطبق في Dockerfile
يُزامن `startup.sh` قاعدة البيانات مع مجلد **NOVA_DATA_DIR** (`/data/nova_data/nova.sqlite`):
- إن وُجدت نسخة دائمة → تُستعاد عند كل تشغيل.
- عند أول تشغيل → تُنشأ من schema وتُحفظ نسخة منها في المجلد.
- في نهاية كل تشغيل → تُحفظ نسخة محدثة.

## المطلوب منك (مرة واحدة فقط)
1. افتح لوحة Render → خدمة Nova Messenger → **Persistent Disks**.
2. اعمل **Mount Persistent Disk** بالمسار: `/data/nova_data`
3. اعمل **Redeploy** (Clear build cache غير مطلوب).

بعد ذلك لن تُفقد قاعدة البيانات أبدًا مع أي بناء جديد، لأن نسخة منها محفوظة على القرص الدائم وتستعاد تلقائيًا عند كل تشغيل.

ملاحظة: إن لم تربط القرص الدائم، يبقى السلوك كما هو (قاعدة بيانات مؤقتة داخل container).
