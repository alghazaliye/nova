# إصلاح القالب الجانبي للإدارة على الهاتف (v5.0.8)

## المشاكل المكتشفة

التصميم الحالي (RTL): عند عرض ≤ 760px:
- `.sidebar { transform: translateX(100%) }` — خطأ في الاتجاه! في RTL، الـsidebar على اليمين (`right: 0`)، و`translateX(100%)` ينقله لليمين (خارج الشاشة) — صحيح إخفاء.
- لكن عند الفتح `.sidebar.open { transform: none }` — صحيح.

**المشكلة الحقيقية المحتملة على الهاتف:**
1. `.main { margin-right: 270px }` لا يوجد media query له عند 1000px (فقط عند 760px يصبح 0) — بين 760px و1000px قد يحدث انكماش.
2. `.sidebar` مثبتة `position: fixed` وz-index: 20، والـtop header مع `position: sticky` — قد يحدث تداخل.
3. عند فتح الـsidebar على الهاتف: لا يوجد backdrop/overlay لإغلاقه عند النقر خارجه، ولا إغلاق تلقائي عند النقر على رابط.
4. زر ☰ في `.top` يوجد فقط عند 760px — على الهاتف (375px) يظهر، جيد.
5. مشكلة `width: min(340px, 34vw)` للبحث مخفي تحت 760px — جيد.

**الإصلاح المطلوب:**
- إضافة overlay داكن خلف الـsidebar عند الفتح على الهاتف مع إغلاق عند النقر.
- جعل `.main` margin-right: 0 عند ≤ 1000px (العرض بين 760-1000 قد يكون معطلًا بسبب 270px margin).
- إغلاق الـsidebar تلقائيًا بعد النقر على رابط.
- تحسين: padding وأحجام مناسبة للشاشات الصغيرة جدًا (375px).
